# Drugcopeia AI

A chat-first, on-device medicine information assistant. One conversation screen (ChatGPT/Claude style), Arabic and English, answers grounded in bundled sources. For education only; not a substitute for a doctor or pharmacist.

- Web: https://husseinsayed994.github.io/Drugcopeia-AI/
- Releases (Android APK/AAB, Windows, macOS, iOS project): https://github.com/husseinsayed994/Drugcopeia-AI/releases
- Separate program from Drugcopeia: https://github.com/hussein-elnagmy/Drugcopeia

## Layout

- `Source/webapp/` web app and chat shell (`ai-shell.*`), `Source/webapp/ai/` assistant pipeline, safety rules and policy
- `Source/android`, `Source/ios`, `Source/macos`, `Source/windows` native shells
- `Source/tests/ai/` assistant test suite; `Source/scripts/` build, sync and privacy tooling
- `PRIVACY.md` human readable data flow, enforced by `Source/privacy.config.json`

## Checks (run in `Source/`)

```
node tests/ai/run-tests.js          # assistant suite
python3 scripts/privacy-check.py    # privacy gate
node scripts/sync-all.mjs --check   # all web copies at one revision
node scripts/verify-project.mjs     # iOS project checks
(cd windows && go test .)           # helper origin guard
```

The web copies (`www`, `windows/www`, iOS and Android assets) are generated by `npm run sync:all`.

## Safety

No free-form generation for pregnancy, breastfeeding, interaction, kidney, pediatric or dose questions: answers come from retrieved sources or the app says it has no data. Dose rules and the dataset still need pharmacist review before public release. See the release notes.
